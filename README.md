# Pydroid-3-Pocket-Python 🐍

A growing collection of small Python games, experiments, and practice programs written on my phone using **Pydroid 3**.

These programs are created during spare moments as a way to practice Python fundamentals and turn simple ideas into working code.

## Projects

### Guess a Number

A random number guessing game that continues until the player finds the correct number.

Concepts practiced:

- Random number generation
- `while` loops
- User input
- Type conversion
- Conditional logic
- Replay controls

### Pop a Balloon

A three-turn scoring game where different balloon colors award or subtract different numbers of points.

Concepts practiced:

- Functions
- Parameters
- Return values
- `if`, `elif`, and `else`
- `for` loops
- Score tracking
- User input

### Greater Than, Less Than

Randomly selects a number and reports whether it is greater than, less than, or equal to five.

Concepts practiced:

- Lists
- `random.choice()`
- Conditional statements
- String conversion
- Output formatting

## Purpose

This repository documents my progress learning Python through small, self-contained programs.

The projects may be simple, but each one focuses on important programming concepts such as:

- Variables
- Functions
- Loops
- Conditionals
- Randomness
- Input and output
- Basic game logic

More programs will be added as I continue experimenting and learning.
